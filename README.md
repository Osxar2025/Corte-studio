# CORTE STUDIO · interfaz Angular (solo frontend)

    npm install
    npm start        # http://localhost:4200

- Marca y textos: `src/app/core/brand.ts`
- Datos de demostración (servicios, barberos, horarios): `src/app/core/demo-data.ts`
- Tokens de diseño: bloque `:root` de `src/styles.css`
- Fotos reales: pasa `[src]="'assets/...'"` a `<app-photo>` (archivos en `public/`)
- Rutas: `/`, `/reservar`, `/ingresar`. Sin backend: todo es visual.
